## Featured Projects

<details>
<summary><b>Velvet Weather — AI-Powered Wardrobe Application</b></summary>

A web application that helps users manage their personal wardrobe and receive clothing recommendations based on current weather conditions.

**Technology Stack**

| Category | Technologies |
|:---|:---|
| Language | Python |
| Backend | FastAPI |
| Database | MariaDB, SQLAlchemy ORM |
| AI/ML | Hugging Face Transformers, BART |
| APIs | OpenWeather API |
| Authentication | OAuth2, JWT |
| Testing | pytest, unittest.mock |
| Other | Alembic, Pydantic, HTML, CSS, JavaScript |

**Key Features**
- Designed a relational database with four entities and 3NF normalization.
- Implemented CRUD operations and user authentication.
- Integrated a pretrained BART model for Zero-Shot clothing classification.
- Connected OpenWeather API for real-time weather information.
- Developed weather-based filtering and recommendation logic.
- Applied modular architecture, Repository Pattern, and Dependency Injection.
- Implemented unit and integration testing.

**Repository:** [Velvet Weather](https://github.com/DarynaLyzun?tab=repositories)
